# Инструмент переноса Deezer

**[English version / Английская версия](README.md)**

PowerShell-скрипт, который переносит настольное приложение Deezer — вместе с настройками и загруженной музыкой — с диска `C:` в любое выбранное вами место, а при необходимости возвращает всё обратно.

## Проблема

Настольное приложение Deezer для Windows не спрашивает, куда устанавливаться. Оно всегда ставится на диск `C:` и туда же загружает всю сохранённую музыку:

```
C:\Users\<имя_пользователя>\AppData\Local\Programs\deezer-desktop   (приложение)
C:\Users\<имя_пользователя>\AppData\Roaming\Deezer                  (настройки + загруженная музыка)
```

Если на диске `C:` мало свободного места, это быстро становится проблемой.

## Решение

Скрипт переносит оба каталога на выбранный вами диск и создаёт в исходных расположениях **символические ссылки** (симлинки) на каталоги. Deezer продолжает работать как прежде — он «думает», что по-прежнему находится в `AppData`, — но все файлы, включая будущие загрузки музыки, на самом деле хранятся на новом диске.

## Возможности

- **Два языка интерфейса** — английский (по умолчанию) и русский, выбор при запуске.
- **Два режима:**
  - **Перенос** — перемещение Deezer в новый каталог;
  - **Восстановление** — копирование всего обратно на диск `C:` и удаление симлинков.
- **Один целевой путь** — вы указываете один базовый каталог (например, `D:\Music`); скрипт создаёт внутри него каталог `Deezer` с двумя подкаталогами: `App` (приложение) и `Data` (настройки и загруженная музыка).
- **Проверки безопасности перед любыми изменениями:**
  - проверка, что Deezer установлен и ещё не перенесён;
  - автоматическое определение имени каталога данных (`Deezer` у новых версий, `deezer-desktop` у старых);
  - проверка свободного места на целевом диске (и на `C:` при восстановлении);
  - предупреждение и запрос подтверждения, если целевой каталог уже существует и не пуст;
  - показ полного плана действий и запрос подтверждения перед выполнением.
- **Самоповышение прав** — скрипт сам запрашивает права администратора через UAC (они необходимы для создания симлинков).
- **Резервная копия при восстановлении** — после копирования файлов обратно на `C:` скрипт спрашивает, удалить ли каталоги на новом диске или оставить их как резервную копию.

## Требования

- Windows Vista или новее (разрабатывалось с расчётом на Windows 10/11);
- Windows PowerShell 5.1 (встроен в Windows) или PowerShell 7+;
- права администратора (скрипт запрашивает их автоматически);
- целевой каталог должен находиться на томе **NTFS** (требование для символических ссылок).

## Файлы

| Файл | Назначение |
|------|-----------|
| `Move-Deezer.ps1` | Основной скрипт |
| `Run-Move-Deezer.bat` | Лаунчер для запуска двойным кликом (предпочитает PowerShell 7, если установлен; иначе использует Windows PowerShell 5.1) |

## Использование

1. Положите `Move-Deezer.ps1` и `Run-Move-Deezer.bat` в одну папку.
2. Дважды кликните `Run-Move-Deezer.bat` (или запустите `.ps1` из терминала: `powershell -ExecutionPolicy Bypass -File .\Move-Deezer.ps1`).
3. Подтвердите запрос UAC на предоставление прав администратора.
4. Выберите язык: `1` — английский (или просто нажмите Enter), `2` — русский.
5. Выберите режим:
   - `1` — **Перенести Deezer в новый каталог.** Укажите целевой базовый каталог (например, `D:\Music`). Просмотрите план действий и подтвердите. Скрипт закроет Deezer, перенесёт каталоги и создаст симлинки.
   - `2` — **Вернуть Deezer обратно на диск C:.** Скрипт сам найдёт перенесённую установку, прочитав цели симлинков, скопирует всё обратно, удалит симлинки и спросит, удалить или оставить каталоги на новом диске.

### Примечания

- Если указанный путь уже заканчивается на `Deezer` (например, `D:\Music\Deezer`), скрипт использует его напрямую, не создавая вложенный `Deezer\Deezer`.
- Если целевой каталог `Deezer` уже существует и не пуст, скрипт предупредит, что **всё его содержимое будет удалено**, и продолжит только после вашего явного подтверждения.
- Скрипт не перезапускает Deezer автоматически — запустите его сами после переноса.

## Как удалить Deezer после переноса

1. Запустите скрипт и выберите режим восстановления (`2`) — это вернёт все файлы на диск `C:` и удалит симлинки.
2. Удалите Deezer обычным способом: Параметры Windows → Приложения → Установленные приложения → Deezer → Удалить.
3. Удалите оставшиеся каталоги на новом диске вручную.

Удаление без предварительного восстановления может оставить нерабочие ссылки и «осиротевшие» файлы на новом диске.

## Отказ от ответственности

Скрипт перемещает данные приложения на вашем диске. Он выполняет множество проверок и запрашивает подтверждение перед каждым необратимым действием, однако вы используете его на свой страх и риск. Резервная копия важных данных перед первым запуском никогда не будет лишней.
